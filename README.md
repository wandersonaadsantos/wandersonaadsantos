## Wanderson Santos

Engenharia de software. Trabalho com fluxo AI-first: agentes dentro do processo de
desenvolvimento, com padrão e medição em volta deles.

Três coisas que guiam o que eu construo:

- **Revisão que mede.** Revisão de código só vale quando mede alguma coisa. Sem prova, é
  opinião com cara de análise.
- **Evidência antes de narrativa.** Sem log, documento ou dado, não é conclusão, é história.
- **Regra sem teste é prosa.** Quando uma regra está escrita, o que importa é o teste que
  prova que ela reprova.
