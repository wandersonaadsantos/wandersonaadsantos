## Wanderson Santos

Software engineering. I work with an AI-first workflow: agents inside the development
process, with standards and measurement around them.

Three things that guide what I build:

- **Review that measures.** Code review is only worth it when it measures something.
  Without proof, it is opinion wearing the face of analysis.
- **Evidence before narrative.** With no log, document or data, it is not a conclusion,
  it is a story.
- **A rule without a test is prose.** Once a rule is written, what matters is the test
  that proves it fails.
